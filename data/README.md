# Data

Download the **County Presidential Election Returns 2000–2024** dataset from the [MIT Election Data and Science Lab](https://electionlab.mit.edu/data). Place the CSV in this directory with the exact filename `countypres_2000-2024.csv`.

The script downloads county-level ACS 5-year estimates for 2012, 2016, 2020, and 2024 from the [U.S. Census API](https://www.census.gov/data/developers/data-sets/acs-5year.html).

The original source datasets are not redistributed in this repository. Consult the providers for their terms, documentation, and any applicable attribution requirements.
